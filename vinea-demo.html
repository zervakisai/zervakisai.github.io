What you are looking at

Real hourly weather for Nemea and Naoussa, run through the real pipeline: a FAO-56 water balance and a four-gate spray-window analysis, one advisory per night. Every figure was produced by features.py — the same code path the nightly batch runs — and frozen into a JSON file this page reads. Nothing is computed in your browser; it renders numbers, it does not produce them.

Two honest labels. This is a replay, not a live service — GitHub Pages serves files, and the system's Postgres, queue, API and worker are not running behind it. And every advisory here is deterministic (degraded=true): no model was called, so the prose is templated rather than written. The physics is identical either way; what an LLM adds is judgement on the borderline nights and language a grower can act on.

Checkable by hand

Open “Check the arithmetic” on any card. ET₀ × Kc, minus effective rain, clamped to [0, TAW]. If the total disagrees with the headline, the headline is wrong.

Missing stays missing

Empty and non-finite cells become None, are counted, and lower confidence — never zero-filled. The confidence figure is that penalty, not a vibe.

Two sites, one codebase

Nemea and Naoussa differ because their weather differs, not because anything was special-cased. Per-tenant weather is enforced end to end.
